Methodology

Understanding how Aarambh Quant Signals are generated

🏗️ Ensemble Architecture

Aarambh Quant uses an ensemble of multiple machine learning models to generate robust signals. Each model captures different market dynamics:

  • Random Forest — Captures non-linear relationships between features and returns. Handles feature interactions naturally.
  • Gradient Boosting (XGBoost) — Sequential learning that focuses on hard-to-predict patterns. Excellent at capturing momentum and trend reversals.
  • Logistic Regression — Linear baseline model for interpretability. Provides probability calibration.
  • SVM (Support Vector Machine) — Finds optimal decision boundaries in high-dimensional feature space.
  • Neural Network — Multi-layer perceptron for complex pattern recognition across 40+ features.

The final signal is a weighted average of all model predictions, with weights dynamically adjusted based on recent model performance (adaptive ensemble).

📈 Feature Engineering

Each ticker is analyzed across 40+ technical features grouped into seven categories:

  • Trend — SMA crossovers (10/20/50/200), EMA, MACD, ADX, Ichimoku Cloud position
  • Momentum — RSI(14), Stochastic, Williams %R, ROC, CCI, Rate of Change
  • Volatility — ATR, Bollinger Band width, historical volatility, Keltner Channel position
  • Volume — OBV, VWAP, volume trend, accumulation/distribution, money flow index
  • Returns — 5/10/20/60/120-day returns, drawdown, Sharpe ratio
  • Regime — Market regime detection using HMM (Hidden Markov Model), VIX correlation
  • Agreement — Cross-model consensus, feature importance alignment

🔄 Regime Filter

Before generating signals, the system identifies the current market regime using a Hidden Markov Model:

  • BULL regime — All models are active. Buy signals receive full weight.
  • NEUTRAL regime — Confidence thresholds are raised. Only high-conviction signals are generated.
  • BEAR regime — Defensive positioning. Buy signals are suppressed, sell signals amplified.

Regime detection uses Nifty 500 breadth data, India VIX levels, and broad market momentum to classify the current state. The regime adjusts gradually using a transition probability matrix.

⚡ Signal Generation

  • Quant Score (0–100) — Weighted ensemble probability × 100. Scores above 65 indicate bullish bias, below 35 bearish.
  • Confidence — Agreement level among models. High confidence = most models agree on direction.
  • Risk Level — Based on ATR volatility, drawdown history, and sector beta. Low/Medium/High classification.
  • Momentum — Short-term (20-day) price trend strength. Strong/Moderate/Weak classification.
  • Stop Loss — Dynamically calculated using ATR(14) × 1.5 from current price.

🧪 Backtesting & Validation

  • Walk-forward validation with 6-month training and 1-month test windows
  • Out-of-sample accuracy tracked across 3-year historical data
  • Signal precision/recall metrics updated weekly
  • Model retrained monthly with fresh data to prevent concept drift
  • Survivorship-bias-free universe using point-in-time Nifty 100 composition
